# 46 比较器阈值、迟滞与确认延时（真实 SPICE）

## 1. 网表结构

```text
Vcell ──R1──┬──R2── 地           （0.5 分压）
            │
            └──R3──┬── C1 ── 地    （RC 延时）
                   │
                   └── S 开关控制端
S：out 与 vdd 之间，VT/VH 定义迟滞；out 经 10 kΩ 下拉
```

S 元件不是理想逻辑门，它有真实导通电阻 `RON=100 Ω`、关断电阻 `ROFF=1 GΩ`。

## 2. ngspice S 模型的迟滞映射（实测）

用阶梯扫描测得：`VT + VH` 处导通、`VT − VH` 处关断，总宽度 `2·VH`。
因此代码中：

```python
VT = 目标阈值 − 迟滞宽度/2
VH = 迟滞宽度/2
```

才能让实测跳闸点等于配置值。这个映射是实测结论，不是假定。

## 3. RC 延时公式

```text
τ = (R3 + R1∥R2) · C1
t_d = −τ · ln[(V_f − V_th)/(V_f − V_0)]
```

本例 `R1=R2=10 kΩ`、`R3=10 kΩ`、`C1=10 µF` → `τ=0.15 s`。

## 7. 常见错误

1. 直接把 VT 当作跳闸阈值（忽略 VH/2）。
2. 忘记分压器戴维南电阻，RC 时间常数算小。
3. 用无迟滞比较器接噪声信号。
4. 把行为模型延时当作 SPICE 延时。
