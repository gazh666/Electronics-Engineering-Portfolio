# 49 被动均衡：电路、电流、功耗与 3S 收敛

## 1. 拓扑

每节电芯并联一条 `R_bal + MOSFET` 支路：

```text
cell+ ──R_bal(100 Ω)──MOSFET── cell−
```

MOSFET 由 3.3 V 逻辑驱动；`R_bal` 承担几乎全部功耗。

## 2. 公式

```text
I_bal = V_cell / (R_bal + R_ds_on)
P_R   = I_bal² · R_bal
P_M   = I_bal² · R_ds_on
P_tot = I_bal² · (R_bal + R_ds_on)
ΔT    = P_tot · R_th
Q_bal = ∫ I_bal dt
```

## 4. 3S 不一致性收敛

12 小时静置均衡、10 s 步长、冻结一阶 RC 模型：

| 指标 | 结果 |
| --- | --- |
| 初始压差 | 130.00 mV |
| 最终压差 | 10.47 mV |
| 压差收敛比例 | 91.95% |
| 停止时间 | 28560 s（7.93 h） |
| 理想时间 | 28608 s |
| 时间相对误差 | 0.17% |
| 累计耗散能量 | 1.339 Wh |

均衡过程中始终选择当前最高单体：cell3 先放电，降到 cell2 附近后切换，
最终三节收敛到最低单体上方 10 mV 内。

## 5. 均衡策略

```text
启动：最高单体 ≥4.10 V 且压差 ≥30 mV
停止：压差 ≤10 mV
同时节数：1（限制局部温升）
禁止：放电中、锁存故障、测量失效
```

## 7. 局限

1. 温升为一阶 `R_th` 估算，未做热仿真。
2. 未建模电阻长期漂移与 PCB 散热。
3. 均衡能量全部以热耗散，效率为 0，这是被动均衡的本质。

## 8. 常见错误

1. 用组电压计算单节均衡功耗。
2. 均衡不设停止回差，反复开关。
3. 把已经被均衡到最低的单体继续放电。
4. 认为被动均衡能"转移能量"。
