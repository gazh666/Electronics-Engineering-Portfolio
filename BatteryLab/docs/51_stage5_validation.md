## 5. 关键真实结果

### 5.1 开关

- 1.007 A 放电，开关压降 37.584 mV，总导通电阻 37.332 mΩ，单管 18.666 mΩ。
- 充电管关断后充电电流 1.00 nA；放电管关断后放电电流 13.2 nA。
- 双管关断、12.6 V 反向：漏电 1.00 nA（限值 1 µA）。
- 输入掉电至 0 V、双管导通：15.809 A 回灌；放电管关断后 13.2 nA。
- 同时关断瞬态：574.5 ns 电流降至峰值 5% 以下，终值 5.98 µA。

### 5.2 栅极驱动

- 峰值电流解析 1.000 A，SPICE 0.975 A（−2.46%）。
- 10–90% 上升时间 44.0 ns，与 `2.2·Rg·Ceq` 一致。
- 驱动功耗 20 mW/管，两管 40 mW @100 kHz。

### 5.3 比较器

- 跳闸 4.250046 V（配置 4.250 V）。
- 释放 4.149736 V（配置 4.150 V）。
- 迟滞 0.100310 V（配置 0.100 V）。
- RC 确认延时 60.865 ms，解析 60.820 ms，误差 0.074%。
- 噪声抖动：带迟滞 1 次，无迟滞 1461 次。

### 5.4 状态机

| 检查 | 实测 |
| --- | --- |
| 过压锁存 | 0.154 s |
| 欠压锁存 | 0.154 s |
| 充电过流锁存 | 0.502 s |
| 放电过流锁存 | 0.202 s |
| 短路锁存 | 0.006 s |
| 过温锁存 | 2.005 s |
| 自动重启 | 0 次 |

### 5.5 均衡

- 三节 4.05 / 4.12 / 4.18 V，均衡电流 41.783 mA。
- 电阻功耗 174.58 mW，MOSFET 0.0698 mW，电阻温升 34.92 ℃。
- 12 h 静置：压差 130.00 → 10.47 mV，收敛 91.95%。
- 停止时间 28560 s，理想 28608 s，误差 0.17%。
- 累计耗散 1.339 Wh。

## 7. 当前模型局限

1. MOSFET 为 ngspice level-1 教学模型，不是真实器件晶体管级模型。
2. 比较器为分立元件等效（S 开关 + RC），不是商业保护 IC 内部电路。
3. 均衡温升为一阶 `R_th` 估算，未做热仿真。
4. 阈值是工程设计值，不是任何商业芯片出厂参数。
5. 未建模 PCB 寄生、EMI、器件批次差异。
6. 未做真实电池充电、过充、过流或短路实验。
