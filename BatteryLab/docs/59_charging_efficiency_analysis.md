# 59 充电效率与损耗分析

数据来源：C01（1 A 恒流）真实 ngspice 末 2 ms 稳态窗口，运行目录
`results/stage6/run_stage6_*`（validation 运行中的 C01 条目）。

## 1. 功率与效率

| 量 | 数值 |
| --- | --- |
| 输入功率 | 11.880 W |
| 电池功率 | 11.644 W |
| 功率级效率 | 98.01% |
| 能量效率（8 ms 积分） | 97.68% |
| 功率守恒残差 | −0.226% |
| ZOH 与梯形积分差 | 1.82 ppm |

能量效率低于功率效率，是因为 8 ms 内输出电容仍在充电（储能项未计入功率级
效率），这属于定义差异而不是损耗。

## 2. 损耗分解

| 损耗项 | 功率 | 占比 |
| --- | --- | --- |
| 二极管导通 | 0.1682 W | 64.0% |
| 电感 DCR | 0.0508 W | 19.3% |
| 通路电阻（30 mΩ） | 0.0301 W | 11.4% |
| 开关导通 | 0.0135 W | 5.1% |
| 输出电容 ESR | 0.00034 W | 0.1% |
| 合计 | 0.2629 W | 100% |

二极管损耗占主导，符合异步 Buck 的预期。若换成同步整流，主要损耗会转为
开关导通与开关损耗，效率分布完全不同——因此本表的 98% **不能**外推到
BQ24610 硬件。

## 3. 一致性校核

1. 功率守恒：`Pin − Pbatt − Ploss = −0.226% Pin`，在预登记 1% 限值内；
   C01/C02/C03/C19 中最大 |残差| 为 0.53%（低功率工况，二极管压降占比更高）。
2. 积分口径：ZOH 为主口径，梯形积分交叉校核，8 ms 内差 1.82 ppm；
   12 个开关级工况中最大 4.98 ppm，限值 100 ppm。
3. 电荷：8 ms 净充入 2.03e-6 Ah，与 1 A × 8 ms 减去软启动缺口的量级一致。

## 4. 限制

- 开关为行为级 SW 模型，未包含栅极驱动、输出电荷与开关损耗；
- 二极管为固定 0.4 V 压降，未包含正向电流依赖与温度；
- 电池内部 R0/R1 损耗不计入功率级效率（属于电池侧）；
- 8 ms 窗口不覆盖温升与稳态热设计。
