# 60 长时充电（ECM 准静态包络）

## 1. 为什么不能把开关级 PI 直接跑秒级

电压环带宽 79.7 Hz，秒级步长离散会直接失稳。长时模型使用**准静态恒压策略**：

```text
I_cv = (V_target − OCV_pack − Vp_pack) / R0_pack
I    = clamp(I_cv, 0, I_cc)
```

它与网表 PI 的物理目标相同（把端电压调到目标），但动态不同：网表 PI 的软启动、
抗饱和、纹波与逐周期限流已被前级验证，长时模型把它们视为快速内环。
两类结果不得拼接成同一条曲线。

## 3. 最大充电时间（C16）

0.2 A 慢充，配置上限 14400 s：

| 量 | 数值 |
| --- | --- |
| 状态 | TIMEOUT |
| 时长 | 14400.0 s |
| 末电流 | 0.2 A |
| 末电压 | 11.6397 V |
| 平均 SOC | 0.694 |
| 充入电量 | 0.800 Ah |

改变的是工况电流（0.2 A），**上限 14400 s 未改**；目的是让上限成为约束，
以验证 TIMEOUT 路径。

## 4. 不一致电池组（C18）

初始 SOC 0.3/0.4/0.5，容量 1.95/2.028/2.10 Ah：

| 量 | 数值 |
| --- | --- |
| 状态 | COMPLETE，3949.5 s |
| 末 SOC | 0.792 / 0.873 / 0.957（极差 0.165） |
| 最大单体电压 | 4.1844 V |
| 末电压 / 末电流 | 12.1620 V / 0.0825 A |
| 保护 | 未锁存（4.184 V < 4.25 V） |
| SOC 一致性残差 | 8.8e-4 Ah（限值 5e-3 Ah） |

要点：4.1844 V 已高于过压**释放**阈值 4.15 V，但未到**触发**阈值 4.25 V。
这意味着如果此前因过压锁存，该组电池在 CV 区内无法自动恢复——与第五阶段
"禁止自动重启"一致。

## 5. 单体过压先于组端 CV（C11，故障注入）

关闭恒压调节（CC-only），初始 SOC 0.55/0.55/0.95：

| 量 | 数值 |
| --- | --- |
| 触发时刻 | 293.5 s |
| 最高单体 | 4.2503 V |
| 触发时组压 | 11.9655 V（< 12.15 V） |
| 锁存故障 | CELL_OVERVOLTAGE |
| 已充入 | 0.0815 Ah |

这验证了"组端电压未到 CV、单体先过压"时保护能立即撤销许可。

**同时得到一个负结果**：在正常恒压调节下，恒压目标 12.15 V 折合 4.05 V/节，
即使 SOC 极差 0.40，最高单体在 CV 区也只到约 4.16–4.19 V，**不会**触发 4.25 V
过压。因此"不一致导致过压"必须在 CC-only 或更高 CV 目标下才成立，不能泛化。

## 6. SOC 外推警告

第三阶段辨识区间为 SOC 0.0106–0.5068。C14/C18 终止时平均 SOC 约 0.86/0.87，
已超出辨识区间，OCV 曲线处于外推段。因此：

- 充电时长、终止电流、能量闭合是模型内自洽结果；
- **绝对 SOC 与"已充到百分之多少"不可作为实测结论**；
- 结果元数据中的 `soc_validity` 字段会标出每个终止 SOC 的外推状态。
