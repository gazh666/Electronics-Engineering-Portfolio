# 70 SOC 误差指标、覆盖率与收敛判据

日期：2026-11-26
对应源码：`analysis/soc_metrics.py`、`analysis/convergence_metrics.py`

## 1. 基本误差

```text
e_k = (SOC_est,k - SOC_ref,k) × 100     单位 pp
MAE  = mean(|e_k|)
RMSE = sqrt(mean(e_k²))
最大误差 = max(|e_k|)
p95  = 95 分位(|e_k|)
```

为什么不只看 RMSE：

- RMSE 对大误差敏感，适合发现"灾难性跳变"；
- MAE 更稳健，适合比较平均精度；
- 最大误差决定安全边界；
- p95 排除极端点，反映常态；
- 终点误差可能被限幅掩盖，必须配合限幅次数。

## 2. 覆盖率与掩码

参考 SOC 只允许 `0 ≤ ref ≤ 1` 参与评价。设总样本 `N`、有效样本 `N_valid`：

```text
coverage = N_valid / N
```

- `estimated is None`（数据缺口、无效电压）不计入误差；
- `ref < 0`（容量口径差异）不计入误差；
- 覆盖率必须与误差一起报告，否则"只挑好样本"会虚高精度。

us06_50 原始端电压查表的覆盖率是 0.9907，原因是 26 个样本端电压超出
OCV 表范围、38 个落在低斜率区。

## 3. 时间加权指标

采样间隔不均匀时，逐样本平均会让高采样率区段主导。使用零阶保持权重：

```text
w_k = t_{k+1} - t_k
MAE_time = Σ |e_k| w_k / Σ w_k
```

本阶段数据的采样较均匀（us06_50 中位 dt 1.003 s、最大 1.559 s），因此时间加权
与逐样本结果很接近（9.297 vs 9.299 pp）。

## 4. 端电压误差

```text
e_V,k = V_pred,k - V_meas,k
```

必须区分：

- **一步预测误差**：修正前预测的 `V_pred`；
- **后验重构电压**：用修正后 SOC 重算的电压。

只有前者能评价观测器预测能力；后者用"修正后的状态"解释"同一时刻的测量"，
会人为变小。本仓库只对前者计算 `calculate_voltage_metrics`。

## 5. 收敛判据

```text
首次满足：|e_k| ≤ 2 pp 连续 60 s
时间缺口 >2 s 时重新计时
```

实现见 `analysis/convergence_metrics.py::find_convergence_time`。

同时报告：

- `entry_time_s`：进入容差带的时间；
- `confirmation_time_s`：确认时刻；
- `post_convergence_max_absolute_error_pp`：确认之后的最大误差；
- `final_error_pp`：终点误差。

为什么要报告收敛后误差：本阶段 ECM 观测器的"收敛后最大误差"仍是 3.05 pp，
说明首次保持 2 pp 不等于永久 2 pp 以内。

## 6. 初始 SOC 实验的边界处理

初始估计 SOC 必须位于 `(0,1)`。若 `SOC0 + error` 越界，记录
`NOT_EXECUTABLE`，不得静默裁剪到 0 或 1。本阶段 us06_50 初始 SOC 约 0.5，
±20 pp 均可行，5 个组合全部 `EXECUTABLE`。

## 7. 真实结果

| 方法 | us06_50 RMSE | 最大误差 | 覆盖率 |
| --- | --- | --- | --- |
| 安时积分 | 0.000 | 0.000 | 1.000 |
| 端电压查表 | 12.778 | 44.94 | 0.9907 |
| 静置校正 | 0.000 | 0.000 | 1.000 |
| ECM 观测器 | 1.729 | 3.05 | 1.000 |

安时积分的零误差只证明积分实现与参考轨迹一致，不证明绝对精度。

## 8. 常见错误

1. 只报 RMSE，不报覆盖率。
2. 把越界参考 SOC 强行截断到 0，再计算误差。
3. 用修正后电压计算"预测误差"。
4. 用终点误差代替整体误差（尤其触底时）。
5. 把"首次收敛"写成"永久收敛"。
