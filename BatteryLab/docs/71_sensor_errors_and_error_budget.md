## 1. 误差预算公式

电压 → SOC：

```text
ΔSOC_pp = ΔV / (dOCV/dSOC) × 100
```

电流固定失调 → 漂移：

```text
ΔSOC_pp = -I_offset × t / (3600 · Q) × 100
```

容量偏差：

```text
ΔSOC_pp = [Δq / Q_assumed - Δq / Q_true] × 100
```

R0 偏差的一阶电压误差：

```text
ΔV = I × (R0_assumed - R0_true)
```

两个关键解释：

1. **正失调终值被下限掩盖**：估计 SOC 先触底，末端误差变成 −0.019 pp，但

2. **白噪声在积分中部分抵消**：10 mA 噪声的 RMSE 只有 0.0086 pp 量级，远小于
   同幅值固定失调。固定偏差有害，零均值噪声相对温和。

## 6. 真实 ngspice 采集链路回放

流程（`experiments/spice_replay.py`）：

```text
真实 19.06 s 电流片段
→ PWL 电流源 → 0.01 Ω 分流
→ INA240A2 规格参考放大器（50 V/V，1.65 V 零点）
→ 1 kΩ / 100 nF RC
→ ngspice 瞬态（1 ms 步长）
→ 12 bit ADC（3.3 V）
→ 零点校准 → 安时积分
```

实测（`validation_summary.json` 的 `spice_replay`）：

| 项 | 数值 |
| --- | --- |
| 真实 SPICE 求解次数 | 2（零电流工作点 + 瞬态） |
| 瞬态点数 | 19127 |
| 窗口 | 19.063 s，位于 us06_50 第 14766.8 s 起 |
| ADC 饱和样本 | 0 |
| 零电流失调 | 2.22e-16 V |
| 区间电荷误差 | **−0.00149%** |
| 区间 SOC 误差 | **−2.18e-6 pp** |
| 电流 RMSE | 0.470 mA |
| 电流最大误差 | 0.918 mA |

边界：只有代表性 19 s 区间是真实开关级/器件级 SPICE；数小时 SOC 误差传播
使用已验证的数学采集模型，**不是**连续数小时联合求解。

## 7. 设计取舍

| 取舍 | 选择 | 理由 |
| --- | --- | --- |
| 噪声模型 | 高斯白噪声 | 教学可复现；不代表真实芯片分布 |
| ADC | 12 bit、3.3 V | 与第四阶段配置一致 |
| 窗口选择 | 自动避开 ADC 饱和 | 不代表所有工况都不饱和 |
| 长时验证 | 数学传播 + 区间 SPICE | 真实全时域 SPICE 成本不可接受 |

## 8. 常见错误

1. 把人工扰动结果写成"芯片实测精度"。
2. 只看终点误差，忽略限幅掩盖。
3. 用白噪声结论推断固定失调无害。
4. 把 19 s SPICE 回放说成"数小时开关级联合仿真"。
5. 忘记零点校准，把放大器/ADC 偏置算成电池电流。
