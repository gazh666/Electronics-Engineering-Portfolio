## 4. 如何正确解读

1. **A 的 0 误差不是精度**：参考轨迹由同一电流、容量、初始 SOC 积分得到，
   A 与参考的一致性只证明积分实现一致。
2. **B 的失败是物理必然**：带载端电压 = OCV − I·R0 − Vp，动态工况下 I 与 Vp
   都在变化，把 V_t 当 OCV 会产生数十 pp 误差。
3. **C 与 A 相同是适用条件不满足**：DST/US06 连续动态段没有 ≥300 s 充分静置，
   校正次数为 0。这不是 C 的实现错误。
4. **D 才是本阶段推荐方法**：它在没有静置的动态工况下，用端电压残差持续
   约束 SOC，RMSE 1.61–2.00 pp。

任务书中"不要求复杂方法在全部指标上优于简单方法"在此得到体现：A 在"与参考
一致性"上不可能被击败，但那不是有用的精度结论。

## 6. 常见错误

1. 用 A 的 0 误差宣称"算法完美"。
2. 因 B 误差大而认为"OCV 方法没用"——静置条件下 B 是有效的。
3. 因 C 与 A 相同而删除 C——它证明了适用条件的重要性。
4. 只比较一个数据集，忽略 50% 与 80% 起始 SOC 的差异。
