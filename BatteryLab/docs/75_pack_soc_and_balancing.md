# 75 3S 电池组 SOC 与均衡电流补偿

日期：2026-11-26
对应源码：`estimation/pack_soc_estimator.py`、`experiments/pack_estimation_experiment.py`

## 1. 串联电池组的电流关系

```text
未均衡：  I_cell_i = I_pack
被动均衡：I_cell_i = I_pack + I_balance_i   (I_balance_i ≥ 0)
```

放电为正、充电为负。被动均衡在该节额外泄放电流，因此该节 SOC 下降更快。
忽略均衡会系统性**高估**该节 SOC。

## 2. 可用容量不能直接相加

```text
理想剩余电荷边界 = min_i(SOC_i · Q_i)
理想可充空间     = min_i((1 - SOC_i) · Q_i)
```

3S 的实际可用容量受最弱电芯限制。把三节 Ah 直接相加是常见错误。

## 3. 实验设置（合成真值）

| 项 | 值 |
| --- | --- |
| 拓扑 | 3S1P |
| 初始 SOC | 0.80 / 0.75 / 0.70 |
| 容量 | 2.03 / 2.00 / 1.97 Ah |
| 放电电流 | 1.0 A，持续 3600 s |
| 静置 | 1800 s |
| 均衡对象 | 第 1 节 |
| 均衡电流 | 4.0 V / (100 Ω + 0.04 Ω) ≈ **39.98 mA** |
| 数据来源 | `synthetic_truth` |

均衡电流由第五阶段设计值计算，是**模型估计电流**，不是实测支路电流。

## 4. 三种估计

| 方案 | 描述 |
| --- | --- |
| A | 所有电芯都用电池组电流积分（忽略均衡） |
| B | 逐节加入均衡电流 |
| C | 逐节加入 +20% 误差的均衡电流 |

运行：`results/stage7/run_stage7_20261126_161834_c31cbc`

| 方案 | 最大单节误差 pp | 平均误差 pp | 末态极差 pp |
| --- | --- | --- | --- |
| A 忽略均衡 | **1.9697** | 0.6566 | 11.500 |
| B 计入均衡 | **0.0000** | 0.0000 | 9.531 |
| C 均衡估计 +20% | 0.3939 | 0.1313 | 9.137 |

教学基准：39.98 mA × 1 h = 39.98 mAh，除以 2.03 Ah ≈ **1.97 pp**，与 A 的
最大误差完全吻合。

结论：

- 忽略均衡的代价约为 2 pp（1 h、40 mA、2 Ah 量级）；
- 计入均衡后误差为 0（同一模型，属实现正确性检查）；
- 均衡电流估计有 20% 误差时，残差约 0.39 pp，仍可接受。

## 5. 为什么 B 的 0 误差不是"精度"

B 与真值使用同一电流关系与容量，仅验证"均衡电流补偿实现正确"。真正的
绝对精度仍依赖电流传感器、容量与初始 SOC。文档不得把 B 的 0 写成"电池组
估计精度 0"。

## 6. 逐节 OCV 校正

`PackSOCEstimator` 可选地接受逐节 `R0`、RC 支路与 OCV 表，调用
`ECMObserver.step` 做逐节电压残差反馈。本阶段的均衡实验未启用该路径（没有
电池组级真实电压），因此结果只反映电流侧补偿。

## 7. 设计取舍

| 取舍 | 选择 | 理由 |
| --- | --- | --- |
| 被动均衡电流方向 | 加到单体放电电流 | 与硬件泄放一致 |
| 可用容量 | 最弱电芯边界 | 串联物理约束 |
| 电压校正 | 可选 | 无真实电池组电压时不启用 |
| 真值来源 | 合成 | 无 3S 实测数据，必须标注 |

## 8. 常见错误

1. 把三节剩余 Ah 相加当电池组容量。
2. 均衡电流符号写反，导致误差翻倍。
3. 用电池组总电压代替单体电压做 OCV 校正。
4. 把合成真值的 0 误差写成实测精度。
