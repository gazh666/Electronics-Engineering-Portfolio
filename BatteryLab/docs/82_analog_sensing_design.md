# 82 模拟采样设计：RC 滤波、Kelvin、ADC 与误差预算

日期：2026-11-26
对象：BQ76922 单体电压通道、SRP/SRN 电流通道、TS1 温度通道。
状态：解析计算与设计约束；没有 PCB，没有板级噪声/精度实测。

## 1. 信号链

```text
电芯/分流电阻 → 串联电阻 + 差分电容 → AFE ADC/库仑计 → 数字滤波与校准 → SOC/SOH
```

每一段都会引入误差。本文只讨论前两段的硬件设计，算法部分见第七阶段文档。
关键原则：ADC 分辨率不是测量精度；RC 截止频率不是采样率；Kelvin 走线不是
"画两根线"。BQ76922 的采样精度首先取决于外部网络与布局，而不是寄存器配置。

## 2. 单体输入 RC 的一阶推导

本设计每根 VC 输入串 47 Ω，差分并 0.22 µF。对差分信号，两个串联电阻相加：

```text
τ  = (47 + 47) × 0.22 µF = 94 × 0.22e-6 = 20.68 µs
fc = 1/(2πτ) = 1/(2π × 20.68e-6) = 7696.08 Hz
A(100 kHz) = -10log10(1 + (100000/7696.08)²) = -22.30 dB
t_1% = -ln(0.01) × τ = 4.605 × 20.68 µs = 95.23 µs
t_r  = ln(9) × τ     = 2.197 × 20.68 µs = 45.44 µs
```

| 指标 | 数值 | 性质 |
| --- | --- | --- |
| 串联电阻 | 47 Ω | 设计选定 |
| 差分电容 | 0.22 µF | 设计选定 |
| 时间常数 τ | 20.68 µs | 计算 |
| 截止频率 fc | 7696.08 Hz | 计算 |
| 100 kHz 衰减 | −22.30 dB | 计算 |
| 1% 建立时间 | 95.23 µs | 计算 |
| 10–90% 上升时间 | 45.44 µs | 计算 |
| 手册推荐 R / C | 20–100 Ω / 0.1–0.22–1 µF | SLUSE86A p.7 |

47 Ω + 0.22 µF 落在推荐区间，这是"合规"的部分。fc=7.7 kHz 意味着对开关噪声
有一定抑制，但也意味着单体电压阶跃后需要约 95 µs 才稳定到 1%。BQ76922 的
采样时序必须留出这段建立时间，否则会读到未稳定的值。

## 3. 共模与差模不是同一个滤波器

上面的 τ 是**差模**时间常数：两个 47 Ω 串联，电容跨接在两条线之间。共模路径
的等效不同，取决于每条线对地的电容与 AFE 输入阻抗。因此不能把 fc=7.7 kHz
直接当成共模干扰抑制能力；若差分电容离引脚很远，走线电感也会让高频衰减偏离
一阶模型。`critical_net_rules.csv` 要求电容靠近 AFE 引脚、采样走线短，就是
为了让"计算的一阶"尽量接近"板上的实际"。

## 4. RC 元件的容差与偏置

| 元件 | 标称 | 容差 | 影响 |
| --- | --- | --- | --- |
| 串联电阻 | 47 Ω | 1% | τ 与 fc 偏移约 ±1% |
| 差分电容 | 0.22 µF | 10% | τ 与 fc 偏移约 ±10% |
| 电容介质 | X7R | 电压/温度系数 | 有效容值下降，fc 上移 |

按 10% 电容容差，fc 可能在约 6996–8551 Hz 之间；再叠加直流偏压与温度，实际值
还需实测。这个范围是算术推算，不是数据手册保证。

串联电阻还会与 AFE 输入形成分压。既有 `hardware/afe/circuit_architecture.md`
给出过一个教学估算：47 Ω 对 100 kΩ 分压臂约 −0.047%，对应 3.6–4.0 V 单体约
0.85–0.94 mV。该估算依赖输入漏电/输入阻抗，本阶段没有从 SLUSE86A 电气特性表
逐项复核，因此标 `NOT_VERIFIED`，不能写进精度承诺。

## 5. Kelvin 采样

分流电阻电压只有 25 mV（2.5 A、10 mΩ）。采样线若共用功率走线，几毫欧的走线
电阻就会叠加可观误差。正确做法：

1. 从分流电阻焊盘内侧单独引出 SENSE_P / SENSE_N；
2. 两条采样线等长、并行、靠近 AFE；
3. 采样线不承载负载电流；
4. 远离功率回路与开关节点；
5. 差分电容靠近 AFE 引脚。

`critical_net_rules.csv` 给 SENSE_P/SENSE_N 的线宽 0.25 mm、间距 0.25 mm、
层 F.Cu、电流 0.01 A。这些是布线约束，不是已经布好的走线；没有 PCB 就无法
验证 Kelvin 是否真的避开功率路径，`layout_review.csv` 把该项标为 `BLOCKED`。

## 6. ADC LSB 与"分辨率不等于精度"

库仑计输入范围 ±200 mV，1 LSB 为 `VREF2/(5×2^15) ≈ 7.568 µV`。10 mΩ 下：

```text
I_FS  = 200 mV / 10 mΩ = 20 A
I_LSB = 7.568 µV / 10 mΩ = 0.757 mA
```

| 量 | 数值 | 说明 |
| --- | --- | --- |
| 库仑计满量程 | ±200 mV | SLUSE86A p.11 |
| 1 LSB | 7.568 µV | 手册公式 |
| 满量程电流 | 20 A | 200 mV / 10 mΩ |
| 电流分辨率 | 0.757 mA | 7.568 µV / 10 mΩ |
| 2.5 A 时压降 | 25 mV | I×R |
| 2.5 A 时功耗 | 62.5 mW | I²×R |

0.757 mA 是量化步距，不是精度。真实电流误差还包含分流电阻 ±1% 初始容差、
±75 ppm/℃ 的 TC、AFE 失调与增益误差、噪声、PCB 热电势与校准残差。
把 0.757 mA 说成"电流精度 0.757 mA"是典型错误。

## 7. 平台区：±5 mV 为什么能放大成几个百分点 SOC

单体电压到 SOC 的换算依赖 OCV 斜率：`ΔSOC_pp ≈ ΔV/(dOCV/dSOC)×100`。

| OCV 斜率 | 1 mV 对应 SOC | ±5 mV 对应 SOC |
| --- | --- | --- |
| 0.5 V/SOC | 0.2 pp | 1.0 pp |
| 0.2 V/SOC | 0.5 pp | 2.5 pp |
| 0.1 V/SOC | 1.0 pp | 5.0 pp |

平台区斜率可能低于 0.2 V/SOC，此时 ±5 mV 的电压误差可以对应 2.5–5 pp 的
SOC 误差。这不是 ADC 变差，而是"电压→SOC"的映射本身变陡。`sensing_requirements.md`
要求斜率 <0.2 V/SOC 时禁止强校正，硬件无法消除平台区，只能在算法层门控。

## 9. 电流通道误差预算

| 误差项 | 量级 | 说明 |
| --- | --- | --- |
| 分流电阻初始容差 | ±1% | WSL2010R0100FEA |
| 分流电阻 TC | ±75 ppm/℃ | 20℃ 温升约 0.15%，40℃ 约 0.30% |
| ADC 量化 | 0.757 mA | 10 mΩ、1 LSB |
| 固定失调 | 目标 ≤2 mA（校准后） | 教学需求，未实测 |
| 噪声 | 目标 ≤5 mA RMS | 教学需求，未实测 |
| 增益校准残差 | 未量化 | NOT_VERIFIED |

第七阶段误差实验说明：固定失调比量化误差危险得多。2 mA 失调在 24 h 积分下
约 2.4 pp（按 2 Ah 容量估算），20 mA 则约 24 pp；0.757 mA 量化误差近似零均值，
长期积分会部分抵消。这也是 BMS 要做零点校准，而不是只追求更高位数 ADC 的原因。

## 11. 同步采样与数据完整性

电压、电流、温度必须对应到同一时间基准，否则会"用旧电压配新电流"。仓库规则
（见 `hardware/fuel_gauge/sensing_requirements.md`）：

| 需求 | 处理 |
| --- | --- |
| 时间戳严格递增 | `validate_sample_sequence` 直接报错 |
| 最大采样间隔 ≤2 s | 超过标记 `DATA_GAP`，不跨缺口积分 |
| 无效测量 | 显式标记 `current_valid/voltage_valid`，禁止填零 |
| 缺口后状态 | SOC 标记不可信，直到重新初始化或状态恢复 |

硬件上，不能假设 BQ76922 的所有通道在同一时刻完成采样；软件必须知道转换
顺序与时间戳，不能把不同时刻的电压和电流当成严格同时。

## 12 自测题

1. 47 Ω + 0.22 µF 的差模 τ、fc、1% 建立时间分别是多少？
   答案要点：τ=(47+47)×0.22 µF=20.68 µs；fc=1/(2πτ)=7696.08 Hz；
   t_1%=4.605τ=95.23 µs。
2. 为什么 0.757 mA 不能称为"电流精度"？
   答案要点：它是 1 LSB 折算的量化步距，不含分流容差、TC、失调、噪声与校准残差。
3. 平台区 ±5 mV 为什么能变成 5 pp 的 SOC 误差？
   答案要点：斜率 0.1 V/SOC 时，1 mV 对应 1 pp，±5 mV 对应 ±5 pp；
   误差被斜率放大，不是 ADC 本身变差。
4. TS1 的 NTC 上拉为什么必须接 REG18？
   答案要点：TS1 输入上限为 VREG18+0.3 V，3.3 V 上拉会超过绝对最大输入。
5. 采样缺口为什么不能填零？
   答案要点：填零会被积分器当成真实零电流，导致 SOC 不漂移的假象；应标记
   `DATA_GAP` 并停止跨缺口积分。
