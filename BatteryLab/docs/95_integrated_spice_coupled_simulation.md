# 95 同一网表联合 SPICE 仿真

## 1. 方法

PowerLab 的 `build_closed_loop_buck()` 把输入源硬编码为理想电压源 `VIN`。为了
让电池成为唯一电源，本阶段：

1. 在 `kaifa_power` 环境中调用 PowerLab **真实构建器**，得到其真实功率级、控制器
   与栅极驱动网表；
2. 移除 `VIN` 元件（PySpice 无公开删除接口，使用其内部元件表并记录键名清单）；
3. 在 `vin` 节点串联真实 3S 电池 ECM（每节 OCV + R0 + Rp‖Cp）与 0.052 Ω 保护通路；
4. 在 `vin` 节点并联 100 µF 输入电容；
5. 用 PySpice 直接求解瞬态，波形写回 BatteryLab 运行目录。

**关键教训（已实测）**：把 `VIN` 置 0 V 而不是删除，会形成 1 mV 低阻源，电池
经 0.36 Ω 内阻向该源灌入约 38 A 电流，测得端电压仅 2.0 V。该结果被判定为错误
拓扑并放弃，随后改为真正移除理想源。运行记录：`results/converter_power_map/
power_map_20261126_172148_ce7dc0` 之前的调试尝试。

## 2. 网表组成

| 部分 | 元件 | 来源 |
| --- | --- | --- |
| 电池 | `OCV1..3`、`R0_1..3`、`RP1..3`、`CP1..3` | 第三阶段辨识 ECM |
| 电流测量 | `VBSENSE`（0 V） | 本阶段 |
| 保护通路 | `BPROT`（受控电阻 0.052 Ω / 1 MΩ） | 第五阶段通路电阻 + 行为开关 |
| 输入电容 | `CIN` 100 µF | 本阶段 |
| 功率级 | `S1`（SWMOD，RON=1 mΩ）、`DFREE`、`L1`+`RDCR`、`C1`+`RESR`、`RLOAD` | PowerLab 真实构建器 |
| 控制器 | `VCREF`、`BCERR`、`BCFF`、`BCPROP`、`BCRAW`、`BCLIM`、`CCINT`、`BCIINT`、`BCRAMP`、`BCPWM`、`ECDRV`、`RCG`、`RCGS` | PowerLab 真实构建器 |

`RLOAD` 固定为 2.5 Ω，因此输出电流由稳压结果决定（约 2 A）。

电池内阻合计 0.231 Ω，电流约 1.0 A，理论压降 0.23 V，与实测 0.233 V 一致。
这不是把电池当作固定输入源的"伪耦合"。

## 5. 本次不能宣称

1. 不能宣称 BMS 检测时间：保护开关在本工况中保持导通；
2. 不能宣称商业 MOSFET 行为：SWMOD 是 1 mΩ 理想受控开关；
3. 不能宣称效率具备量产意义：损耗只区分"输入-输出差"；
4. 不能把 2.5 Ω 电阻负载结果外推到恒流/恒功率负载。
