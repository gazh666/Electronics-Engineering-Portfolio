# 98 长期放电运行

## 1. 模型与方法

`system_models/long_duration_system.py`：3S 一节 ECM（OCV + R0 + Rp‖Cp，第三阶段
辨识参数）+ 已验证静态功率映射 + 第五阶段保护许可。步长 5 s，最长 8 h。
不使用纳秒级 SPICE 做数小时仿真，也不把 5 s 步长当成保护时序证据。

运行：`results/stage9/system_lifetime/discharge_20261126_173652_f67325`
（16 个 SOC × 负载工况 + 1 个不一致工况）

## 3. 为什么大多数工况停在"有效域外"

放电极深时电池有效电压 `Ueff` 与串联内阻压降之和，会要求转换器输入低于已验证的
9.0–9.6 V 下限（取决于负载）。此时 `solve_power_map_operating_point()` 在网格内
找不到根，脚本以 `OUT_OF_VERIFIED_DOMAIN` 终止并写出两侧残差，例如：

```
no verified operating point: Vin would be below minimum of verified range
[9.600, 12.600] V (Ueff=9.748 V, residual at bounds +0.0071/+3.0128 V)
```

这是**拒绝外推**，不是求解失败。要达到 2.80 V 欠压终止，必须扩展功率映射的低压端；
本阶段没有为了让曲线好看而放宽稳态判据（见文档 94 第 4 节）。

## 4. 容量与初始 SOC 同时不一致

初始 SOC 0.40/0.30/0.20，容量 2.0281/1.9000/1.8000 Ah，负载 1.5 A：

| 项 | 值 |
| --- | --- |
| 运行时间 | 0.443 h |
| 终止原因 | `BATTERY_MODEL_LIMIT`（最低节 SOC 先到辨识下限） |
| 终止时 SOC | 0.2317 / 0.1204 / 0.0104 |
| 终止时最低节电压 | 3.0784 V |
| 终止时端电压 | 9.9687 V |
| 最终 SOC 极差 | 0.2213 |
| 未使用电荷（估算） | 0.661 Ah |

这说明不一致电池组的可用能量由最弱节决定：其它节还有电，但放电已被最弱节终止。

## 5. 不能宣称

1. 5 s 步长不能证明微秒级保护响应，保护时序证据见文档 97；
2. 转换器是已验证静态映射，不是开关级波形；
3. SOC 超出辨识区间的 8 个工况属于参数外推，不能当作实验数据；
4. 未使用电荷是按比例估算，不代表真实可转移电量。
