# 3S AFE 设计计算书（教学研究稿）

所有数值均为**公式计算或真实 ngspice 仿真**，不是芯片实测。单位统一为 V/A/Ω/F/℃。

## 1. 单体差分放大器

四电阻差分放大器：

```text
Vout = (1 + R2/R1) * (Vhigh*R4 + Vref*R3)/(R3+R4) - (R2/R1)*Vlow
```

取 R1=R3=100 kΩ，R2=R4=50 kΩ：

```text
k = R2/R1 = 0.5
Vout = Vref + 0.5*(Vhigh - Vlow) = 0.2 + 0.5*Vcell
```

| 单体电压 | 理论输出 | 说明 |
| --- | --- | --- |
| 2.50 V | 1.450 V | 量程下限 |
| 3.60 V | 2.000 V | 教学基准 cell1 |
| 3.80 V | 2.100 V | 教学基准 cell2 |
| 4.00 V | 2.200 V | 教学基准 cell3 |
| 4.25 V | 2.325 V | 量程上限 |

输出始终位于 3.3 V ADC 输入范围内，正常工作不饱和。

### 1.1 运放引脚共模

```text
Vp = (Vhigh*R4 + Vref*R3)/(R3+R4)
Vn = (Vlow*R2 + Vout*R1)/(R1+R2)
```

顶部单体 11.4 V / 7.4 V 时：

```text
Vp = (11.4*50k + 0.2*100k)/150k = 3.9333 V
Vn = (7.4*50k + 2.2*100k)/150k = 3.9333 V
```

量程上限 12.75 V / 8.5 V 时约 **4.383 V**，低于 5 V 供电，但裕量只有约 0.62 V。
**电池节点共模 9.4 V 不是运放引脚共模 3.93 V**，两者必须分开核对。

## 2. 输入 RC 滤波

```text
Rdiff = 2*47 = 94 Ω
tau = Rdiff*Cdiff = 94*0.22e-6 = 20.68 µs
fc = 1/(2*pi*tau) = 7696.08 Hz
tr(10–90%) = 2.197*tau = 45.43 µs
ts(1%) = 4.605*tau = 95.23 µs
100 kHz 理论衰减 = -10*log10(1+(100k/7696.08)^2) = -22.300 dB
```

真实 ngspice 结果：fc = 7695.23 Hz（相对误差 −0.011%），100 kHz 衰减 −22.301 dB。

### 2.1 滤波电阻的负载效应

输入电阻与 100 kΩ 分压臂串联：

```text
R1_eff = 100k + 47 = 100047 Ω
R3_eff = 100k + 47 = 100047 Ω
```

对 3.6/3.8/4.0 V 单体，输出相对无滤波理论降低约 **0.846/0.893/0.940 mV**。
这是系统误差，可被两点校准吸收，但必须在设计计算中显式列出。

## 3. 双向电流检测

```text
Vshunt = I*Rshunt
Vout = Vref + G*Vshunt = 1.65 + 50*0.01*I = 1.65 + 0.5*I
I = (Vout - 1.65)/0.5
```

| 电流 | 分流压降 | 理论输出 | 分流功耗 |
| --- | --- | --- | --- |
| −2.5 A | −25 mV | 0.40 V | 62.5 mW |
| 0 A | 0 mV | 1.65 V | 0 mW |
| +2.5 A | +25 mV | 2.90 V | 62.5 mW |
| +3.5 A | +35 mV | 3.40 V | 122.5 mW（ADC 饱和） |

ADC 折算电流分辨率：

```text
I_lsb = LSB/(G*Rshunt) = (3.3/4096)/(50*0.01) = 1.611 mA
```

INA240A2 输入失调 ±25 µV（max）折算电流误差：

```text
I_offset = 25e-6/0.01 = 2.5 mA
```

输出滤波 1 kΩ + 0.1 µF：

```text
fc = 1/(2*pi*1000*0.1e-6) = 1591.55 Hz
```

## 4. ADC

```text
LSB = Vref/2^N = 3.3/4096 = 0.805664 mV
code = floor(Vin/LSB)
Vdec = (code+0.5)*LSB
最大量化误差 = 0.5 LSB = 0.402832 mV
```

折算到单体输入端（增益 0.5）：**1.611 mV**；折算到电流（0.5 V/A）：**1.611 mA**。
量化步距不是采集精度，系统精度还需叠加电阻失配、运放失调、参考偏差、噪声与校准残差。

## 5. NTC 温度

```text
Rntc(T) = 10k*exp(3950*(1/(T+273.15) - 1/298.15))
Vntc = 3.3*Rntc/(10k+Rntc)
Rntc = 10k*Vntc/(3.3-Vntc)
T = 1/(1/298.15 + ln(Rntc/10k)/3950) - 273.15
```

| 温度 | NTC 电阻 | 分压 |
| --- | --- | --- |
| 0 ℃ | 33.6 kΩ | 2.543 V |
| 25 ℃ | 10.0 kΩ | 1.650 V |
| 60 ℃ | 5.0 kΩ | 0.657 V |

25 ℃ 灵敏度约 **−36.7 mV/℃**；ADC 量化折算温度约 **0.022 ℃**。
自热功耗 `P = V²/R = 1.65²/10k = 272 µW`；缺少真实耗散系数，自热温升 **NOT_VERIFIED**。

## 6. 电阻功率与耐压

以顶部通道 12.75 V 为例：

```text
I_divider = 12.75/(100k+50k) = 85 µA
P_100k = I²*100k = 0.72 mW
P_50k  = I²*50k  = 0.36 mW
```

0603/0.1 W 电阻有充足裕量；100 kΩ 两端压差约 8.5 V，远低于 0603 额定电压。
0.1% 薄膜电阻用于 R1–R4，1% 厚膜用于 47 Ω 滤波电阻。

## 7. 容差预算结论

- 电压最坏情况线性叠加 **30.887 mV**，RSS **23.189 mV**；主导项是 0.1% 四电阻失配在 9.7 V 共模下的 **22.679 mV**。
- 电流最坏情况 **37.736 mA**，RSS **15.868 mA**；主导项是 1% 分流电阻容差 **12.5 mA**。
- 温度最坏情况 **0.246 ℃**，RSS **0.225 ℃**；主导项是 R25 容差 **0.224 ℃**。

结论：1000 组随机样本校准后满足 10 mV/20 mA/1 ℃ 目标，但**最坏情况电压/电流预算超过目标**，不能宣称有保证裕量。详见 `docs/38_calibration_and_error_budget.md`。
