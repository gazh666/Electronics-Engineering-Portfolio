# BQ24610 参考架构与第六阶段教学模型的对照

本文件只做架构级对照，所有 BQ24610 参数均标注为 `datasheet_specification`，
表示来自 TI 数据手册的标称规格；本项目没有在真实 BQ24610 硬件上测量任何数据。

## 1. 一致的物理目标

| 目标 | BQ24610 | 第六阶段模型 |
| --- | --- | --- |
| 拓扑 | 同步降压 | 异步降压（二极管替代低边管） |
| 充电阶段 | 预充 → 恒流 → 恒压 → 终止 | 软启动 → 恒流 → 恒压 → 终止 |
| 恒压目标 | VFB 分压设定 | 12.15 V（3 × 4.05 V） |
| 恒流设定 | ISET1/ISET2 | 1.0 A |
| 终止 | 终止电流 + 安全定时 | 0.1 A 保持 60 s / 14400 s 上限 |
| 温度保护 | TS + NTC | 复用第五阶段 0–45 ℃ 充电窗与 65 ℃ OTP |
| 输入限流 | ACSET | 未建模（固定 18 V 理想源） |
| 输入掉电隔离 | ACFET + BATDRV | 未建模，C07/C20 专门暴露该风险 |

## 2. 本项目相对真实芯片的简化

1. **没有输入 ACFET 与电池 BATDRV 隔离**：因此 C07（输入掉电、PWM 仍开）与 C20
   （输入掉电、PWM 关闭）用于量化"缺少反向隔离"的后果，而不是宣称芯片行为。
2. **低边用二极管**：效率因此偏低（C01 约 98% 是理想二极管模型 + 低电流的结果，
   不能外推到真实同步整流的损耗分布）。
3. **开关频率不同**：教学模型 100 kHz / 100 µH / 220 µF，BQ24610 典型 600 kHz，
   电感量级约 10 µH。两者的纹波与环路带宽不可直接互换。
4. **控制环位置不同**：教学模型的 PI 在 SPICE 行为源内，用于学习"网表内闭环"；
   BQ24610 用内部跨导放大器 + 外部补偿网络，补偿设计方法不同。
5. **保护执行机构不同**：教学模型只做许可判定与波形核查，不模拟 FET 开断后的
   电气重分布；第五阶段的保护状态机是独立离散模型。

## 3. 不能从本阶段结果得出的结论

- 不能声称"BQ24610 在本电池组上能达到 98% 效率"；
- 不能声称"真实芯片在输入掉电时反向电流为 4.7 mA"（C20 只说明本简化网表）；
- 不能把 12.15 V / 1 A 的补偿参数直接移植到 600 kHz 的真实芯片；
- 不能把短窗（8–12 ms）保护回灌结果当成完整充电周期的保护行为。

## 4. 若要进入硬件阶段必须补做

1. 按数据手册确认 24 引脚定义、热焊盘与功率回路布局；
2. 用真实器件模型重做效率与温升；
3. 加入 ACFET/BATDRV 与输入反接保护后重跑 C07/C20；
4. 对 NTC 分压、ISET 电阻、TTC 电容做容差与温漂分析；
5. 在硬件上测量恒压精度、终止电流与保护响应时间。
