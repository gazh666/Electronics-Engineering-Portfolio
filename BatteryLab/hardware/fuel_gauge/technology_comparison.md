# 电量计技术路线对比（面向 3S INR18650-20R 教学包）

日期：2026-11-26
定位：教学与算法验证设计，**不是量产 BMS 选型结论**。

## 1. 四类"电量计"不是同一层东西

| 层次 | 典型器件 | 主要职责 | 是否直接输出 SOC |
| --- | --- | --- | --- |
| 模拟前端 / 监测保护 | TI BQ76922（同类：BQ769x2 系列） | 逐节电压、温度、电流采样，过压/欠压/过流/短路保护，被动均衡驱动 | 否，需主控算法 |
| 充电控制器 | TI BQ24610 | 降压型 CC-CV 充电控制、输入/电池保护 | 否 |
| 独立电量计 | TI BQ34Z100-R2（同类：BQ34z100 系列） | 基于电压/电流/温度与电池模型做 SOC/SOH 估计 | 是（算法内部） |
| 本阶段实现 | BatteryLab `estimation/` | 安时积分 + OCV 校正 + ECM 残差反馈 | 是（研究级） |

把 BQ76922 说成"电量计芯片"、或把 BQ24610 的充电终止当作 SOC=100%，
都是常见概念错误。

## 2. BQ34Z100-R2（定性）

公开资料表明它属于**阻抗追踪（Impedance Track）类**电量计，面向多节锂电/磷酸铁锂
等化学体系，支持通过外部电流检测电阻与电压/温度输入估计 SOC、SOH，并需要通过
配置与学习过程获得电池特性。

必须注意（以官方 Datasheet 为准，本仓库不复述未核实的具体数值）：

- 具体支持串数、电压/电流测量范围、通信接口、采样率、SOC 精度承诺：**以官方
  Datasheet 为准 / 本阶段 NOT_VERIFIED**；
- "Impedance Track"是 TI 的专有算法名称，其内部是否等价于 EKF、是否使用
  卡尔曼滤波，公开材料不足以推导，**不得写成 EKF**；
- 学习/配置需要完整充放电循环与稳定温度条件，教学包的 25℃ 公开数据不足以
  复现其配置流程。

## 3. BQ76922（定性）

BQ769x2 系列是**电池监测与保护 AFE**，典型能力包括逐节电压采样、温度采样、
库仑计数（coulomb counter）硬件累加、过压/欠压/过流/短路保护、被动均衡开关
驱动。它提供的是"高精度测量 + 硬件保护"，SOC 仍需主控 MCU 运行算法。

因此在本项目架构中，BQ76922 对应 `sensing/` + `protection/` + `circuits/` 的
硬件抽象，而不是 `estimation/` 的替代品。

## 4. BQ24610（定性）

BQ24610 是独立降压充电控制器，负责 CC-CV 充电环路、输入电流限制、充电终止
与状态指示。第六阶段已用行为级 + SPICE 验证其控制律，但：

- 充电器进入终止状态 **不等于** 电池 SOC=100%；
- 充电器的电流/电压读数不能直接当作电量计输出；
- 充电终止后的 SOC 仍需估计器给出，并允许 <100%。

## 5. 与本项目算法的对应关系

| 能力 | 本仓库实现 | 量产器件对应 |
| --- | --- | --- |
| 电流/电压/温度采样误差 | `sensing/`、`analysis/estimation_error_budget.py` | BQ76922 + 外部 ADC |
| 库仑计数 | `estimation/coulomb_counter.py` | BQ769x2 硬件库仑计数器 |
| OCV 反查 | `estimation/ocv_estimator.py` | 电量计内部 OCV 表 |
| 电压残差反馈 | `estimation/ecm_observer.py` | Impedance Track 类算法的公开替代 |
| 容量/SOH | `health/capacity_soh.py` | 电量计 SOH 功能 |
| 均衡电流补偿 | `estimation/pack_soc_estimator.py` | AFE 均衡 + 主控算法 |

## 6. 明确不可宣称的内容

1. 不得声称本仓库观测器等价于 BQ34Z100-R2 的内部算法。
2. 不得声称 25℃ 单一温度验证覆盖车规全温区。
3. 不得声称教学限值（RMSE ≤3 pp 等）是任何器件的规格书指标。
4. 不得在无真实老化数据时给出循环寿命或 RUL 结论。
