# BatteryLab MOSFET 保护真实性复验

> 真实 ngspice Level-1 N-MOSFET 背靠背共源 + 显式体二极管 + 栅极 RC；不是行为电流源。

## 1. 历史 2.5 ns 伪迹判定

| 事件 | 时间(s) |
|---|---|
| 故障注入时刻 | 0.012000000 |
| 栅极关断指令 | 0.012010000 |
| 历史“电流抑制” | 0.012000003 |
| 相对栅极指令 | -9.9975 µs（早于指令） |
| 历史抑制比 | 0.001231 |

- 结论：抑制早于栅极指令 9.9975 µs，物理不成立，判定为行为电流源钳位伪迹，永久保留为无效记录。
