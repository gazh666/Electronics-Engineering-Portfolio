## 2. 系统负载阶跃：改善 31.79% 不等于 PASS

| 项 | 值 |
|---|---|
| 偏差 | 843.0 mV → **574.97 mV**（改善 31.79%） |
| 原动态限值 | **300 mV**（`configs/system_validation.yaml`：`load_step_deviation_v.max=0.3`） |
| 额定输出 | **5 V / 2 A**（`configs/system_config.yaml`：`rated_output_current_a=2.0`） |
| 阶跃 | 2.5Ω → 1.25Ω @5V ≈ **2A → 4A** |

**判定**：574.97 mV 仍 **> 300 mV**，未满足原限值；且 4A 已 **超出 5V/2A 额定**，属**过载研究工况**。
**正确表述**："过载阶跃研究下偏差由 843mV 降至 575mV，仍超 300mV 限值且超出额定电流。"
**禁止表述**："负载阶跃 PASS"或"满足 300mV 动态指标"。
