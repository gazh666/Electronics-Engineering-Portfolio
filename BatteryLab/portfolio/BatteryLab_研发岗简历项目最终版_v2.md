# BatteryLab 最终简历量化成果

> 4 条，全部基于真实运行结果；AI 辅助不作为个人独立掌握的能力宣传。

## 1. 3S 电池等效电路建模与参数辨识

- CALCE INR18650-20R 公开数据，Rint / 一阶 RC / 二阶 RC 端电压预测对比；
- FUDS 50/80% 独立验证 RMSE 26.705 → 22.385 → 22.175 mV；
- 低 SOC 0–5% 误差单独报告（bjdst_80 二阶 RMSE 157.7 mV），未用验证数据调参。

## 2. 模拟采集链路误差预算与校准

- 最坏情况预算：电压 30.887 mV、电流 37.736 mA；
- 0.01% 匹配网络 + 低失调放大器 + 优化参考 + 两点校准剩余误差 → 3.837 mV / 6.666 mA；
- 1000 组蒙特卡洛两点校准后 RMSE 0.8730 mV / 0.8396 mA，真实 ngspice 角点最大偏差 3.49 µV。

## 3. 电池保护与充电控制

- 真实背靠背 N-MOSFET 网表替代行为电流源，识别并剔除历史 2.5 ns 伪迹；
- 故障→电流抑制 0.871 µs，栅极下降 44.6 ns，串联导通电阻 30.67 mΩ；
- 软启动 0→5 ms 使启动能量 0.2492 → 0.1368 J（−45.1%）；抗积分饱和条件积分使 CV 过冲 3.257 → 2.068 mV（−36.5%）。

## 4. 电源系统联合仿真

- 3S ECM + 100 kHz Buck + 保护级闭环联合仿真，TestLab 4/4 用例 PASS；
- 优化 LC（68 µH/330 µF）+ 配套控制器：纹波 24.54 → 21.00 mV、负载阶跃偏差 843.00 → 574.97 mV、效率 94.158 → 95.206%（+1.048 个百分点）。
