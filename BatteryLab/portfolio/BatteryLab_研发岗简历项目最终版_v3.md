## 二、简历项目描述（4 条）

1. **AFE 采集链路误差预算与校准**：为 3S 锂电 BMS 建立"解析最坏预算 + 真实 ngspice 角点 + 1000 组蒙特卡洛"双口径评估，候选 D 匹配网络将电压/电流理论最坏预算降至 **3.837 mV / 6.666 mA**，统计校准 RMSE 为 **0.8730 mV / 0.8396 mA**（预算与统计分别报告）。

2. **保护 MOSFET 物理级时序验证**：基于真实 ngspice 器件模型复现故障→电流抑制链路，独立功率通路 **0.871 µs**、联合系统 **119.8 µs（RISK）**；识别并永久剔除早期 "2.5 ns 源钳位" 仿真伪迹，保留失败与修复记录。

3. **闭环级联与抗积分饱和工程评估**：开关级联合仿真对比基准/优化 LC 与调参控制器，效率 **95.21%**、纹波 **21.0 mV**；如实记录 PI 带宽分离（1.86×）与软启动 CC 误差（20.61 mA）等未达标项，不粉饰。

4. **EDA 硬件设计（KiCad 10.0.8）**：独立完成 BMS 与同步 Buck 充电器两套可编辑原理图（BQ76922 / BQ24610，关键引脚审计 **0 失败**）、两块 **4 层** PCB（放置/网表/板框完成，原理图-PCB 一致性 **0 项**），真实导出 Gerber/钻孔/STEP；ERC **0 错误**，PCB 布线为待完成项（PARTIAL）。

## 三、面试时必须主动声明的真相

- 3.837 mV / 6.666 mA 是**理论最坏预算**，不是实测硬件误差；候选 D 未打样。
- 0.871 µs 是**独立功率通路**，不是整机 BMS 保护时间；联合系统为 119.8 µs（RISK）。
- 负载阶跃 574.97 mV **仍超 300 mV 限值**且**超出 5V/2A 额定**，属过载研究、不达标。
- 电池模型**仅 25℃ 有效**，SOC 辨识窗口 0.011–0.507，续航结论 LIMITED。
- EDA 为**研究草稿**：PCB 未布线（71/67 未连接）、BMS 有 4 个 QFN 细间距 DRC、板框 102×122mm，**不可投产**。
