## 三、简历描述（4 条）

1. **电池状态估计与验证链**：用 CALCE 公开数据构建 Rint / 一阶 / 二阶 RC 模型，FUDS 独立验证
   RMSE 22.2–26.7 mV；对低 SOC 误差（RMSE 157.7 mV）与二阶参数弱可辨识性如实标注，不扩大有效域。
2. **采样 AFE 误差预算**：建立分压—差分—ADC 全链路误差模型，最坏情况由 30.887 mV / 37.736 mA
   优化到 3.837 mV / 6.666 mA，并把理论预算与统计校准 RMSE（0.875 mV / 0.841 mA）分开报告。
3. **保护与充电闭环**：背靠背 MOSFET + 栅极 RC 保护通路，故障→电流抑制 0.871 µs；同步 Buck 充电
   CC 误差 1.09 mA、效率 98.01%；同时保留联合系统 119.8 µs 与环路带宽比 1.86× 两项失败结论。
4. **EDA 硬件设计**：在 KiCad 10 完成 BMS 与充电器 2 套可编辑原理图、2 块 4 层 PCB（100.1×72.1 mm），
   完成全部网络布线（620 段 / 96 过孔）与 In1 地平面设计，真实 DRC 0 错误、0 未连接，板面积较初版缩小 42.0%；
   QFN 0.4 mm 间距用局部 0.15 mm 规则解决。仍保留 DRC 警告、ERC 告警与高频未验证等局限。
