# BatteryLab 项目学习与面试实战手册

> 对应最终源码与真实运行结果；生成运行 `run_20261126_185854_86cbd0`。全部为软件仿真与公开数据重放。

## 1. 项目链路

CALCE INR18650-20R 公开数据 → Rint/一阶/二阶 ECM → 分压-差分-ADC AFE → 背靠背 N-MOSFET 保护 → 被动均衡 → CC-CV 充电 → 3S + Buck 系统联合仿真 → TestLab 接口判定。

## 3. 源码索引

- `hardening/common.py`：时间平均、能量、对照与 Run 目录。
- `hardening/afe_worst_case.py`：误差贡献与预算；`hardening/afe_optimization.py`：候选与蒙特卡洛。
- `hardening/protection_physical_validation.py`：真实 MOSFET 网表与事件提取。
- `hardening/charging_control_comparison.py`：软启动、PI 网格、抗饱和。
- `hardening/low_soc_model_analysis.py`：分区误差与模型对照。
- `hardening/system_candidate_validation.py`：LC 与控制器候选复验。
- `hardening/domain_audit.py`：有效域、SOH、LLC 分类。
- `hardening/eda_status.py`：KiCad 与交付物状态。

## 8. 真实性边界

- 公开数据不是本人采集；SPICE 不是硬件实测；ERC/DRC 不等于硬件验证；测试数量不是电气性能。
- 失败项永久保留：AFE 基线、PI 5× 分离、低 SOC、LC 谐振。
