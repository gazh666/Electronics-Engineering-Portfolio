# 11 Buck 降压变换器原理

本文解释非同步 Buck 变换器的基本工作原理，以及第三阶段仿真中实际使用的拓扑。
理论公式属于 `analytical_theory`；文中引用的电压、电流数值来自真实 ngspice 瞬态仿真
（默认工况：Vin=12 V、fsw=100 kHz、D=5/12、L=47 µH、C=100 µF、R=2.5 Ω）。

## 1. 为什么 Buck 能降压

Buck 变换器通过一个高频开关把输入电压斩波，再用电感和电容把脉冲序列平滑成较低的
直流输出电压。开关导通时电感两端承受 `Vin - Vout`，电感电流上升并储能；开关关断时
电感电流不能突变，必须通过续流二极管继续流动，此时电感释放能量。

稳态下电感电流的平均值不变，因此电感在一个周期内的「伏秒」积分必须为零：

```
∫VL dt = 0        (一个完整开关周期)
```

这就是**电感伏秒平衡**。对理想 Buck：

```
导通区间: VL = Vin - Vout，持续时间 Ton = D*T
关断区间: VL = -Vout，      持续时间 Toff = (1-D)*T
(Vin - Vout)*D*T = Vout*(1-D)*T
=> Vout = D * Vin
```

同理，输出电容在一个周期内充放电电荷相等（**电容电荷平衡**），所以稳态平均输出
电压不会持续漂移，只保留开关频率附近的纹波。

## 2. 实际拓扑

```
        S1 (电压控制开关)
 vin ──/ ────────────── sw ──[VSENSE 0V]── lx ── L1 ──┬── out ──┬── RLOAD ── GND
                       │                              │         │
                       │                              └── C1 ───┘
                       │
                     DFREE (阳极 GND，阴极 sw)
```

- `VIN`：12 V 直流输入源。
- `VPWM`：0/5 V 方波，驱动开关栅极 `gate`。
- `S1`：ngspice `SW` 电压控制开关，导通电阻 `RON=0.001 Ω`，关断电阻 `ROFF=1e6 Ω`。
- `DFREE`：续流二极管，阳极接地、阴极接开关节点 `sw`。
- `VSENSE`：0 V 串联电压源，只用于读取真实电感支路电流，不改变拓扑。
- `L1 = 47 µH`、`C1 = 100 µF`、`RLOAD = 2.5 Ω`。

## 3. 两条电流路径

**开关导通（D·T 区间）**

```
Vin → S1 → sw → VSENSE → L1 → out → 负载
                              └→ C1（充电）
```

二极管反偏截止。电感电流线性上升，斜率 `dIL/dt = (Vin - Vout)/L`。

**开关关断（(1-D)·T 区间）**

```
GND → DFREE → sw → VSENSE → L1 → out → 负载
```

电感通过二极管续流，电感电压被钳位在约 `-Vout`（实际还要减去二极管正向压降），
电流线性下降，斜率 `dIL/dt = -Vout/L`。

默认工况实测：开关节点 `sw` 在约 0 V 与约 12 V 之间切换，电感电流在
1.5925 A 与 2.2327 A 之间周期变化（纹波 0.6402 A），与上述两条路径一致。

## 4. 理想 CCM 关系与纹波

理想连续导通模式（CCM）下：

```
Vout = D * Vin
ΔIL  = (Vin - Vout) * D / (L * fsw)
ΔVout = ΔIL / (8 * fsw * C)
Iout = Vout / R
Ipeak = Iout + ΔIL/2
Ivalley = Iout - ΔIL/2
```

默认参数的理论值：`Vout=5.000 V`、`ΔIL=0.620567 A`、`ΔVout=7.757 mV`、
`Ipeak=2.3103 A`、`Ivalley=1.6897 A`。

真实 SPICE 结果（含 1 mΩ 导通电阻与二极管正向压降）：
`Vout=4.7813 V`、`ΔIL=0.6402 A`、`ΔVout=8.139 mV`。
输出电压比理想值低 4.37%，属于非理想器件压降造成的模型差异，不是数值错误。

## 5. CCM 与 DCM 的区别

- **CCM（连续导通）**：整个周期内电感电流都大于零，电流波形为连续三角波。
- **DCM（断续导通）**：负载较轻时，电感电流在周期结束前降到零并保持为零，
  二极管截止，开关节点出现浮空/振铃段（理想模型下为 0 V 附近）。
- **BCM（临界）**：电感电流恰好在周期结束时降到零。

理想临界条件：

```
Iboundary = ΔIL / 2
Rboundary = Vout / Iboundary
```

默认参数下 `Iboundary=0.3103 A`、`Rboundary=16.114 Ω`。第三阶段用 2.5 Ω（重载）、
16.1144 Ω（临界附近）、50 Ω（轻载）三种负载做了真实对比，详见
`docs/16_ccm_dcm_analysis.md`。

## 6. 开环与闭环的区别

第三阶段实现的是**固定占空比开环** PWM：占空比由配置给定，不根据输出电压调整。
因此：

- 负载变化时输出电压会明显变化（50 Ω 时实测升到 7.2189 V）；
- 启动时没有软启动，输出峰值达到 7.8463 V，超调 64.1%；
- 这些是真实的开环特性，不能解释为「稳压电源」性能。

闭环控制、软启动、电流环属于后续阶段，本阶段未实现。
