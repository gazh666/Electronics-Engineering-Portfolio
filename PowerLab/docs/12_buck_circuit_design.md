# 12 Buck 电路参数设计（12 V → 5 V）

本文给出第三阶段使用的初始设计计算。所有公式结果标记为 `analytical_theory`；
SPICE 实测值单独列出，二者不混用。

## 1. 设计目标

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 输入电压 Vin | 12 V | 直流 |
| 目标输出电压 Vout | 5 V | 开环设计目标 |
| 额定输出电流 Iout | 2 A | 对应 2.5 Ω 满载 |
| 开关频率 fsw | 100 kHz | 周期 10 µs |
| 输出电压纹波目标 | ≤ 50 mVpp | 项目设计目标，不是商业规格 |

## 2. 占空比

理想 CCM：

```
D = Vout / Vin = 5 / 12 = 0.4166667
Ton = D * T = 4.1666667 µs
Toff = 5.8333333 µs
```

实际电路存在开关导通电阻和二极管正向压降，同样占空比下实测
`Vout = 4.7813 V`（相对理想值 -4.37%）。若要精确得到 5 V，需要闭环调节或
略微增大占空比，本阶段不做闭环，因此保留 `D=5/12`。

## 3. 电感电流纹波与电感选择

```
ΔIL = (Vin - Vout) * D / (L * fsw)
```

取 `L = 47 µH`：

```
ΔIL = (12 - 5) * 0.4166667 / (47e-6 * 100e3)
    = 0.620567 A
```

约为额定电流 2 A 的 31%，属于常见设计范围（通常取 20%–40%）。若要求更小纹波，
可用反推公式：

```
L = (Vin - Vout) * D / (fsw * ΔIL_target)
```

代码位置：[buck_theory.py](file:///PowerLab/analysis/buck_theory.py) 中的
`inductor_for_ripple()`。

真实 SPICE 实测 `ΔIL = 0.6402 A`，比理论大 3.17%，原因是开关导通电阻与二极管
压降使实际伏秒关系偏离理想公式。

## 4. 输出电容与电压纹波

理想电容纹波：

```
ΔVout = ΔIL / (8 * fsw * C)
```

取 `C = 100 µF`：

```
ΔVout = 0.620567 / (8 * 100e3 * 100e-6) = 7.757 mV
```

反推最小电容：

```
C = ΔIL / (8 * fsw * ΔVout_target)
```

代码位置：`capacitance_for_ripple()`。真实 SPICE 实测 `ΔVout = 8.139 mV`，
比理想值大 4.92%，因为实际 `ΔIL` 略大，且模型包含开关瞬间的数值细节。

## 5. 负载、峰值电流与临界点

满载电阻：

```
R = Vout / Iout = 5 / 2 = 2.5 Ω
```

峰值与谷值电流：

```
Ipeak  = Iout + ΔIL/2 = 2 + 0.3103 = 2.3103 A
Ivalley = Iout - ΔIL/2 = 2 - 0.3103 = 1.6897 A
```

临界负载：

```
Iboundary = ΔIL / 2 = 0.3103 A
Rboundary = Vout / Iboundary = 16.114 Ω
```

真实 SPICE 默认工况：`Ipeak=2.2327 A`、`Ivalley=1.5925 A`，均低于理想值，
因为实测平均输出电流为 1.9126 A（输出电压较低）。

## 7. 尚未完成的器件选型

本阶段只做**电路级近理想模型**验证，以下真实器件参数尚未考虑：

- 电感饱和电流、额定 RMS 电流、DCR、磁芯损耗；
- 电容耐压、ESR、ESL、纹波电流额定值、寿命与降额；
- MOSFET 导通电阻随温度变化、栅极电荷、开关损耗、体二极管；
- 二极管的结电容、反向恢复（肖特基与快恢复差异）；
- 驱动电路、死区、PCB 寄生参数。

因此当前结果只能说明拓扑与公式在理想化模型下自洽，不能作为硬件选型依据。
