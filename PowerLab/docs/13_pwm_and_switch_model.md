# 13 PWM 激励与电压控制开关模型

## 1. PWM 的基本量

PWM（脉冲宽度调制）用固定频率的方波控制开关：

- **频率 fsw**：每秒开关次数，本阶段 100 kHz。
- **周期 T = 1/fsw**：10 µs。
- **占空比 D**：高电平时间占周期的比例，本阶段 5/12 ≈ 0.4167。
- **导通时间 Ton = D·T**：4.1667 µs。

代码：[pwm.py](file:///PowerLab/circuits/pwm.py) 中的 `PWMParameters`。

## 2. SPICE PULSE 参数映射

ngspice 的 `PULSE(V1 V2 TD TR TF PW PER)` 中，`PW` 是**高电平平台宽度**，
不包含上升/下降边沿。由于开关阈值位于 0 V 与 5 V 的中点（2.5 V），且
`TR = TF`，有效导通时间为：

```
Ton = PW + (TR + TF)/2
=> PW = D*T - (TR + TF)/2
```

本阶段实际参数：

| 参数 | 数值 | 配置来源 |
| --- | --- | --- |
| V1（低电平） | 0 V | `pwm.low_voltage_v` |
| V2（高电平） | 5 V | `pwm.high_voltage_v` |
| TD（延迟） | 10 µs | `pwm.delay_s` |
| TR（上升） | 20 ns | `pwm.rise_time_s` |
| TF（下降） | 20 ns | `pwm.fall_time_s` |
| PW（平台） | 4.1466667 µs | `pulse_width_s` |
| PER（周期） | 10 µs | `period_s` |

实际网表中的 PWM 行：

```text
VPWM gate 0 DC 0V PULSE(0.0V 5.0V 1e-05s 2e-08s 2e-08s 4.146666666666667e-06s 1e-05s)
```

模块会校验：

- 频率、占空比、边沿、延迟的有限性与正负；
- `D ∈ (0,1)`；
- 高电平必须大于低电平；
- 上升 + 下降时间必须短于一个周期；
- 平台宽度必须为正；
- `max_step_time_s ≤ T / 20`（每周期至少 20 个内部步长）。

## 3. 有限边沿的影响

理想 PWM 是瞬时跳变；实际驱动存在上升/下降时间。本阶段使用 20 ns 边沿，
相对于 10 µs 周期只有 0.2%，对占空比影响很小，但能让开关过程在数值上更平滑。

需要强调：**实测占空比不是把配置值抄回来**。分析层
（[buck_waveforms.py](file:///PowerLab/analysis/buck_waveforms.py) 的
`analyze_pwm_waveform()`）从真实 `gate_v` 波形做 2.5 V 阈值线性插值，统计每个完整
周期的周期与脉宽。默认工况实测：

- 平均频率：99999.99999999999 Hz；
- 平均占空比：0.41666666666667407。

与配置值的误差分别约为 1.5e-16（相对）和 7.4e-15（绝对），属于浮点舍入量级。

## 4. SW 电压控制开关模型

Buck 主开关使用 ngspice 内置 `SW` 模型：

```text
.model SWMOD SW (ROFF=1000000.0 RON=0.001 VH=0.1 VT=2.5)
```

| 参数 | 数值 | 含义 |
| --- | --- | --- |
| RON | 0.001 Ω | 导通电阻 |
| ROFF | 1e6 Ω | 关断电阻 |
| VT | 2.5 V | 阈值电压 |
| VH | 0.1 V | 迟滞宽度 |

导通/关断门限：

```
Vturn_on  = VT + VH/2 = 2.55 V
Vturn_off = VT - VH/2 = 2.45 V
```

PWM 高电平 5 V > 2.55 V，低电平 0 V < 2.45 V，因此可以可靠开关。
配置类会调用 `validate_gate_levels()` 做这项检查。代码：
[switch_models.py](file:///PowerLab/circuits/switch_models.py)。

## 5. 续流二极管模型

```text
.model DFREE D (IS=1e-06 N=1.0 RS=0.001)
```

| 参数 | 数值 | 含义 |
| --- | --- | --- |
| IS | 1 µA | 饱和电流 |
| N | 1.0 | 理想因子 |
| RS | 0.001 Ω | 串联电阻 |

方向为**阳极接 GND、阴极接 sw**：开关导通时二极管反偏；开关关断时电感电流
从 GND 经二极管流向 sw，形成续流通路。

## 6. 为什么当前模型不等于 MOSFET 模型

`SW` 是理想化压控电阻，缺少真实 MOSFET 的关键特性：

- 没有栅极电荷、米勒平台、驱动电流与开通/关断延迟；
- RON 不随栅压、电流、温度变化；
- 没有体二极管、输出电容 Coss、结电容；
- 没有开关损耗（开通/关断交叠损耗）与反向恢复；
- 二极管也没有结电容和反向恢复时间。

因此本阶段只能验证**拓扑、PWM 时序、稳态与纹波公式的一致性**，不能用于效率、
EMI、热设计或器件应力评估。这些内容属于第四阶段。
