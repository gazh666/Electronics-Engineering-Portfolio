# 21 非理想 Buck 五模型 A–E

## 1. 设计原则

五个模型共用同一套电气工况（12 V → 5 V、2 A、100 kHz、D = 0.4166667、47 µH、100 µF、2.5 Ω），
只逐项增加非理想因素。Model A **直接复用第三阶段构建器**，保证基线可追溯。

构建入口：`circuits/nonideal_buck.py::build_nonideal_buck(config, variant)`；
变体表：`VARIANT_TABLE`；运行：`simulations/nonideal_buck_runner.py`。

| 模型 | 开关 | 二极管 | 电感/电容 | 浮动驱动 | 寄生电容 |
| --- | --- | --- | --- | --- | --- |
| A | 第三阶段 `SW` | 理想教学二极管 | 理想 | 无（对地 PWM） | 无 |
| B | `SW` | 理想教学二极管 | + DCR 50 mΩ / ESR 30 mΩ | 无 | 无 |
| C | `SW` | 非理想二极管 | + DCR / ESR | 无 | 无 |
| D | Level 1 NMOS | 非理想二极管 | + DCR / ESR | 有（RG = 10 Ω） | 无 |
| E | Level 1 NMOS | 非理想二极管 | + DCR / ESR | 有 | Cgs/Cgd/Cds |

## 2. 统一测量结构

B–E 在每个器件端口串入 0 V 传感源，保证功率边界互不重叠：

- `VDSENSE`：vin → drain，用于漏极电流与 VDS；
- `VDIOSENSE`：gnd → diode_a，用于二极管电流；
- `VLSENSE`：sw → lx，用于电感电流；
- `VCSENSE`：out → c_esr，用于电容电流；
- `VDRV`：浮动驱动源，其支路电流给出驱动器输出电流。

A 没有这些节点，由 `analysis/buck_waveforms.extract_nonideal_waveforms` 用第三阶段已有的
`gate_v / vout / inductor_current` 推导等效量，因此 A 与 B–E 的列名一致、可直接对照。

### 3.1 逐项差异

- **A → B（无源寄生）**：DCR 使 Vout 下降 93.4 mV、损耗增加 169.6 mW；
  ESR 几乎不改平均效率，但纹波从 8.1 mVpp 升到 19.0 mVpp。
- **B → C（非理想二极管）**：二极管损耗从 0.408 W 升到 0.435 W，Vout 再降 14.7 mV。
  原因是 `VF ≈ 0.40 V @ 2 A`，明显高于理想二极管模型。
- **C → D（NMOS + 浮动驱动）**：MOSFET 网络损耗 1.59 mW → 31.59 mW，
  效率再降 0.32 个百分点；Vout 略降 8.2 mV。D 没有 Cgs/Cgd，栅极电流几乎为零，
  因此开关能量不能代表真实器件。
- **D → E（寄生电容）**：MOSFET 网络损耗 31.59 → 51.68 mW，RG 损耗从 0 升到 9.90 mW，
  总损耗 +28.9 mW，效率再降 0.18 个百分点。

### 3.2 必须说明的数值现象

- Model C 的 `ID` 绝对峰值 6.689 A，远高于 A/B 的 2.2 A。定位后发现它出现在开关跳变的
  单个采样点上（相邻点可相差 10 A 以上，步长约 3e-10 s），属于 `CJO` 与理想开关共同造成的
  数值尖峰，不是持续电流。文档 23 因此同时报告 p99.9。
- Model A 的残差 5.60e-4 W 略高于 B–E，原因是 A 使用第三阶段理想二极管模型，
  其端口电压/电流定义与 B–E 的统一测量口径存在细微差异；残差比例仍为 5.9e-5，远低于 15% 告警线。
- 所有模型都没有把残差塞进任何器件损耗；残差只作为独立项报告。

## 4. 限制

- 五个模型的 L/C 数值相同，但无源器件仍为线性时不变模型。
- D/E 的 NMOS 是 Level 1 教学模型（文档 18），不能据此给出真实器件效率排名。
- 未包含 PCB 寄生、死区时间、驱动器传播延迟与二极管反向恢复电荷。
- 目标输出 5 V 从未被强行钳位；Vout 的偏差是工况与损耗的真实结果，没有为凑 5 V 修改数据。
