# 23 能量平衡与器件应力

## 1. 为什么还要做能量平衡

损耗分解回答“损耗去哪了”，能量平衡回答“能量是否守恒”。两者共用同一份真实波形，
但检查的对象不同：前者是各端口平均功率，后者是“供电能量 = 输出能量 + 损耗能量 + 残差”。

模块：`analysis/energy_balance.py`。

判定阈值：

| 残差比例 `|residual| / (Pin+Pdrv)` | 状态 |
| --- | --- |
| ≤ 5 % | `ok` |
| 5 % – 20 % | `warning` |
| > 20 % | `excessive` |

Model E 实测（200 µs 稳态窗口）：

| 指标 | 值 |
| --- | --- |
| 残差功率 | −3.66e-5 W |
| 残差 / 供电功率 | **−3.90e-6** |
| 状态 | `ok` |

残差为负且极小，说明在非均匀步长积分下功率守恒到 10⁻⁶ 量级，没有出现“凭空多出能量”。

### 2.1 关于峰值与 p99.9

`drain_current_peak_a` 是原始绝对最大值。在 Model C 中它被开关瞬间的孤立数值样本抬高到
6.689 A，而相邻采样点只有约 2 A。为解决“峰值被单个数值点主导”的误导，本阶段新增
`drain_current_p999_a`：

- Model E：峰值 = p99.9 = 2.1854 A，说明没有孤立尖峰；
- Model C：峰值 6.689 A，但持续电流仍在 2 A 量级，尖峰应视为数值现象。

文档 18/21 与验收报告都同时给出两者，避免把数值尖峰当作真实应力。

## 3. 这些数字能说明什么、不能说明什么

能说明：

- 在该教学模型与工况下，MOSFET 关断时承受约 12.4 V（输入 12 V + 开关节点负冲）；
- 二极管反向承受约 12 V；
- 栅极驱动没有超过 10 V，也没有明显负压。

不能说明：

- 不是任何器件的安全工作区（SOA）结论；
- 没有雪崩、短路、热失控、EMI 评估；
- 没有封装热阻与自热，不能据此给出结温；
- 峰值应力不是数据手册额定值，不能用于选型。
