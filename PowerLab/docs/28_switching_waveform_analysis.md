# 28 开关波形分析

本文解释开通时间、关断时间、延迟时间、上升/下降时间、VGS 与 VDS、电压电流重叠、
开关能量、栅极电阻影响和时间分辨率。

代码位置：`analysis/switching_analysis.py`，核心函数 `analyze_switching`、
`interpolate_crossing`、`_transition_intervals`、`_edge_from_intervals`；
开关能量复用第四阶段 `analysis/loss_analysis.py` 的 `switching_energy`。
统一入口是 `analysis/performance_analyzer.py` 的 `PerformanceAnalyzer.analyze`。

真实结果来自 `results/performance/run_20261125_143425_ddc5d86e/switching_metrics.json`
（Model E 基线，5 ms 瞬态）。

## 1. 阈值定义

VDS 的低/高电平取窗口原始样本的 1 %/99 % 分位：

$$
V_{10}=V_L+0.1(V_H-V_L),\qquad V_{90}=V_L+0.9(V_H-V_L)
$$

实测：$V_L=0.0335$ V、$V_H=12.410$ V、$V_{10}=1.271$ V、$V_{90}=11.172$ V。

- **开通（turn-on）**：VDS 从 $V_{90}$ 下降到 $V_{10}$，对应上管导通、漏源电压塌落；
- **关断（turn-off）**：VDS 从 $V_{10}$ 上升到 $V_{90}$，对应上管关断、漏源电压抬升。

## 2. VGS 与 VDS

栅极驱动配置（`configs/nonideal_buck_config.yaml` 的 `gate_driver`）：

| 参数 | 取值 |
| --- | ---: |
| 驱动高电平 | 10 V |
| 栅极电阻 $R_g$ | 10 Ω |
| 栅源下拉电阻 | 100 kΩ |
| 命令上升/下降时间 | 20 ns |
| 驱动器类型 | 理想浮地源（Model E） |

VGS 决定沟道是否形成；VDS 由负载电流、电感续流与器件导通电阻共同决定。
本项目延迟时间以**栅极命令的 50 % 时刻**为参考，而不是 VGS 的某个绝对值：

- 开通延迟 = VDS 开始下降时刻 − 命令上升沿 50 % 时刻
- 关断延迟 = VDS 开始上升时刻 − 命令下降沿 50 % 时刻

## 3. 上升时间与下降时间

- 上升时间：VDS 由 $V_{10}$ 升到 $V_{90}$ 的 10–90 % 时间（关断过程）
- 下降时间：VDS 由 $V_{90}$ 降到 $V_{10}$ 的 10–90 % 时间（开通过程）

“开通时间/关断时间”在本文中分别指完整的开通过程（含延迟与下降时间）与
关断过程（含延迟与上升时间），报告中把延迟与 10–90 % 过渡时间分开列出，
避免把两者混为一个数。

为什么边沿时间标 `NOT_RESOLVED`：`configs/performance_analysis.yaml` 中
`switching.minimum_edge_samples: 10`，实测每边仅 3 个原始样本

## 5. 电压电流重叠与开关能量

开关过程中 VDS 与漏极电流同时非零，瞬时功率

$$
p_{sw}(t)=v_{DS}(t)\,i_D(t)
$$

在过渡区间积分得到开关能量：

$$
E_{on}=\int_{t_{10\%}^{on}}^{t_{90\%}^{on}}v_{DS}i_D\,dt,\qquad
E_{off}=\int_{t_{10\%}^{off}}^{t_{90\%}^{off}}v_{DS}i_D\,dt
$$

单周期能量与平均开关功率：

$$
E_{cycle}=E_{on}+E_{off},\qquad
P_{sw}=\frac{\sum E}{T_{window}}
$$

| 指标 | 数值 |
| --- | ---: |
| 导通能量（10 个边沿合计） | 103.183 µJ |
| 关断能量（10 个边沿合计） | 102.029 µJ |
| 总开关能量 | 205.212 µJ |
| 单周期开关能量 | 20.521 µJ |
| 开关平均功率 | 20.005 mW |

20.005 mW 与第四阶段同一工况的开关损耗一致，说明本阶段沿用了同一套能量口径，
没有为“更好看”而更换积分区间。

## 6. 为什么能量可用而边沿时间不可用

能量是积分量：采样稀疏时梯形积分仍有界，局部误差被区间平均，只要端点覆盖
完整过渡即可。边沿时间是斜率推断：两点之间插值，样本不足时对噪声、量化和
步长变化非常敏感。因此两者必须分开判定：`switching_power_w` 为 `AVAILABLE`，
`switching_turn_on_time_s` 为 `NOT_RESOLVED`。

## 7. 栅极电阻的影响

栅极电阻 $R_g$ 与器件输入电容构成 RC 充电：

$$
\tau \approx R_g\left(C_{gs}+C_{gd}\right)
$$

本模型外部电容 $C_{gs}=1$ nF、$C_{gd}=0.2$ nF，$R_g=10$ Ω，估算
$\tau\approx12$ ns，与配置的命令边沿 20 ns 同量级。工程含义：

- $R_g$ 增大 → 栅极充电变慢 → di/dt、dv/dt 降低 → 开关能量与重叠损耗增加，
  但振铃和 EMI 尖峰减小；
- $R_g$ 减小 → 开关更快 → 开关损耗下降，但可能加剧振铃、过冲与栅极振荡；
- 实际选型要在效率、EMI、器件 SOA 之间折中。

本阶段**没有**做不同 $R_g$ 的参数扫描（属于后续阶段的参数扫描任务），
上述只是由模型参数和 RC 关系给出的量级解释，不冒充仿真扫描结果。

## 8. 时间分辨率

时间分辨率由三件事共同决定：

1. 仿真器实际输出步长（本工况最小步长 5×10⁻⁸ s，最大步长 2.5×10⁻⁸ s 配置）；
2. 边沿区间内的原始样本数（本例 3 个）；
3. 插值方法（线性插值，不引入额外物理信息）。

因此报告同时给出 `duration_s`、`sample_count`、`max_gap_s` 与 `status`。
读者看到 `NOT_RESOLVED` 时应理解为“数值存在但分辨率不足”，而不是“测量失败”。

## 9. 面试题

1. 10–90 % 上升时间为什么对采样率敏感？
   它本质是两点间的斜率测量，样本越少，插值结果对单点误差越敏感。
2. 插值得到的 4.218 ns 能直接写进 datasheet 吗？
   不能。必须同时给出样本数与 `NOT_RESOLVED`，否则把数值精度误当成物理分辨率。
3. 开关能量积分为什么比边沿时间更可信？
   积分具有平均效应，只要区间端点覆盖完整，单个采样误差对总能量影响有限。
4. 导通延迟与关断延迟为什么不同？
   栅极驱动、米勒平台、输出电容和负载电流方向都会造成差异。
5. 增大栅极电阻会怎样影响效率与 EMI？
   开关变慢，开关损耗上升，但 dv/dt、di/dt 降低，振铃与高频发射减小。
6. 为什么延迟参考点是栅极命令 50 %，而不是 VGS 的固定电压？
   命令 50 % 由驱动定义、可复现；VGS 的绝对阈值受米勒平台和器件参数影响。
7. 如何把单周期开关能量换算成平均功率？
   $P_{sw}=E_{cycle}f_{sw}$；本项目用总能量除窗口时长，避免周期计数误差。
