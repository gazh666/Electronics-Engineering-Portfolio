# 65 Web 用户使用指南

## 启动平台

在项目根目录执行：

```powershell
conda run -n kaifa_power python -m streamlit run app.py --server.port 8502
```

浏览器访问 `http://127.0.0.1:8502`。健康检查端点：
`http://127.0.0.1:8502/_stcore/health`。平台默认仅监听本机，不提供账号体系。

首次使用建议依次完成：总览 → 电路仿真 → 历史记录（重建索引）→ 性能分析。

## 页面功能说明

平台共 8 个页面，按“工作台 / 分析与实验 / 数据”分组。所有页面都只展示真实文件内容；
没有结果时显示空状态，不生成示例波形或占位指标。

## 1. 总览 `dashboard`

| 项目 | 说明 |
| --- | --- |
| 输入 | 无 |
| 数据来源 | `results/environment_*/environment.json`、`results/run_index.json`、`results/web_jobs/*/job.json`、第八阶段验收 JSON |
| 展示 | 环境探测卡片、历史运行/SPICE/派生分析/活跃任务计数、最近 8 条运行、最近 8 个任务、第八阶段参考 |
| 操作 | 无提交操作；导航到其他页面 |
| 限制 | 环境卡片是静态报告，不触发重新求解；第八阶段结论只读 |

## 2. 电路仿真 `circuit_lab`

| 项目 | 说明 |
| --- | --- |
| 输入 | 模型选择（6 个）+ 工程单位参数 + 非理想 Buck 变体 A–E |
| 校验 | 范围、符号、`max_step ≤ step`、Buck 目标电压 < 输入电压 |
| 操作 | 提交 `circuit_simulation`，轮询真实进度，取消 |
| 输出 | 任务状态、工况进度、SPICE 调用次数、最新运行指标、波形查看入口 |
| 限制 | 单任务仅一个工况；不提供任意网表编辑 |

## 3. 性能分析 `performance`

| 项目 | 说明 |
| --- | --- |
| 输入 | 从历史运行中选择一个含波形且非批量的运行 |
| 操作 | 提交 `performance_analysis`（派生），或选择最近运行直接查看 |
| 展示 | 指标卡、PASS/FAIL/NOT_RESOLVED/NOT_VERIFIED 判定、检查表、波形、导出 |
| 数据来源 | 新结果标记 `spice_derived`，并记录 `parent_run_id` |
| 限制 | 扫描/Monte Carlo/收敛目录没有单一波形，拒绝重分析 |

## 4. 闭环控制 `closed_loop`

| 项目 | 说明 |
| --- | --- |
| 输入 | 控制模式（闭环/开环对照）、功率级变体 D/E/SW、负载与输入工况、Kp/Ki、占空比限幅、前馈、抗饱和、时长与步长、软启动 |
| 校验 | 占空比限幅有序、增益非负、时长 0.5–20 ms、步长 5–5000 ns、`max_step ≤ step` |
| 操作 | 提交 `closed_loop_experiment`，查看真实进度与取消 |
| 输出 | 稳态窗口电压/纹波/电感电流/效率、PWM 统计、步长回退记录、波形与导出 |
| 限制 | 工况来自 `configs/disturbance_cases.yaml`，不允许任意扰动脚本 |

## 5. 批量实验 `batch`

三个标签页：

1. **参数扫描**：选择参数（电感、电容、开关频率、负载、DCR、ESR、占空比），输入 2–40 个值；
   每个值一次真实非理想 Buck 瞬态；失败点保留并标记。
2. **Monte Carlo**：样本数 5/10/30、随机种子、容差百分比；复用第八阶段抽样与统计；
   明确标注“假设分布，不代表量产良率”。
3. **数值验证**：2–5 个时间步，逐点真实求解并给出收敛结论。

| 限制 | 说明 |
| --- | --- |
| 预算 | 扫描与验证受 120 次 SPICE 调用上限约束 |
| 样本 | Monte Carlo 最大 30（`job_limits.yaml`） |
| 结果 | 汇总表、分布图、收敛图、导出均来自真实运行目录 |

## 6. 数值验证与验收 `validation`

| 项目 | 说明 |
| --- | --- |
| 输入 | 时间步序列（ns） |
| 操作 | 提交 `numerical_validation` |
| 展示 | 当前收敛结论、历史收敛运行列表与摘要、第八阶段验收参考 |
| 限制 | 第八阶段结论仅作参考，不自动重跑；硬件验证项保持 NOT_VERIFIED |

## 7. 历史记录 `history`

| 项目 | 说明 |
| --- | --- |
| 输入 | 关键字、运行类型、数据来源、状态、分页大小 |
| 操作 | 读取索引、按需重建索引、查看运行详情、查看/导出波形、导出摘要/指标/检查表 |
| 展示 | 元数据表（不含波形数组）、统计分布、运行详情 |
| 限制 | 索引只存元数据；波形按需读取并抽样绘图，导出使用完整原始文件；不修改任何运行目录 |

## 8. 关于与限制 `about`

| 项目 | 说明 |
| --- | --- |
| 展示 | 版本、能力清单、6 个模型、证据等级、任务与数据位置、手动验收说明 |
| 作用 | 明确 simulation-only 边界，禁止把仿真结果表述为硬件实测 |
| 限制 | 不提供账号系统、硬件测量、EMI/热实测 |

## 9. 通用交互约定

- 每个浏览器会话有独立 `session_id`，任务在 `job.json` 中记录归属。
- 提交前检查是否有活跃任务；重复请求与并发超限均有明确提示。
- 任务进度只显示真实工况计数与 SPICE 调用次数；没有可信内部进度时不显示百分比。
- 失败页面显示真实异常摘要与日志末尾，不使用伪造数据填充。
