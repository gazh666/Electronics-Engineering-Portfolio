# 09 VirtualDUT 虚拟被测电源行为模型

## 1. DUT 与 DC-DC 电源

DUT（Device Under Test，被测设备）指自动化测试中正在被激励与测量的对象。
本项目模拟一个标称 12 V 输入、5 V 输出的降压型 DC-DC 电源模块：
输入侧由虚拟程控电源供电，输出侧由虚拟电子负载拉载，测量由模型适配层完成。

DC-DC 电源的基本用途是把一个直流电压转换为另一个稳定的直流电压。
降压（Buck）拓扑通过开关管、电感与电容储能实现能量传递，本模型不描述
开关过程，只描述输入/输出之间的**稳态**电压、电流、功率与效率关系。

## 2. 稳态行为模型与 SPICE 仿真的区别

| 维度 | 本行为模型 | SPICE 电路仿真 |
| --- | --- | --- |
| 描述对象 | 输入-输出稳态代数关系 | 器件级电路方程与开关波形 |
| 时间尺度 | 无时间序列 | 微秒/纳秒级瞬态 |
| 参数来源 | 配置文件的等效参数 | 器件模型与寄生参数 |
| 输出 | Vout / Iout / Pin / Pout / 效率 / 状态 | 节点电压、支路电流波形 |
| 用途 | 测试软件联调、判定逻辑验证 | 电路设计与器件选型 |

因此本模型**不能**给出纹波、开关损耗、环路稳定性、瞬态恢复时间等指标。

## 3. 模型参数

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 标称输入电压 | 12 V | 正常工作输入 |
| 最低允许输入 | 9 V | 低于此值判欠压 |
| 最高允许输入 | 16 V | 高于此值判过压 |
| 标称输出电压 | 5 V | 空载理想输出 |
| 最大输出电流 | 2 A | 超过判过流 |
| 等效输出电阻 | 0.02 Ω | 负载调整率的来源 |
| 预设转换效率 | 90% | 模型参数，不是实测值 |

参数保存在 `configs/dut_config.yaml`，由 `VirtualDUT.from_yaml()` 读取并校验。
修改参数无需改核心算法。

## 4. 核心公式

```text
Vout = Vnominal - Iout × Rout
Pout = Vout × Iout
Pin  = Pout / efficiency
Iin  = Pin / Vin
Ploss = Pin - Pout
```

其中 `Iout` 在电子负载输入关闭时按 0 A 处理；`Vin` 为电源电压设定值。

等效输出电阻 `Rout` 表示负载电流增大时输出电压的下降量，是简化的
“负载调整率”来源。例如 1 A 时下降 0.02 V，2 A 时下降 0.04 V。

效率固定为 0.90，因此 `Pin = Pout / 0.9`、`Ploss = 0.1 × Pin`。
这是模型假设，不代表真实器件在全部工况下都保持 90%。

空载时 `Pout = 0`、`Pin = 0`，效率不可定义，模型返回 `None`，
既不返回 0% 也不返回 100%，避免误导。

## 5. 工作状态与判定顺序

状态判定顺序固定如下（先匹配者生效）：

1. `OUTPUT_OFF`：程控电源输出关闭；
2. `UNDERVOLTAGE`：输入电压 < 9 V；
3. `OVERVOLTAGE`：输入电压 > 16 V；
4. `OVERCURRENT`：负载需求 > 2 A；
5. `INPUT_CURRENT_LIMIT`：计算得到的输入电流需求超过电源限流；
6. `NORMAL`：其余情况。

保护采用简化的“停机”策略：非 `NORMAL` 时输出电压、电流、功率全部为 0，
效率为 `None`。真实电源可能采用恒流、折返、打嗝或锁存保护，本模型不模拟。

输入电流限制检查发生在正常工作计算之后：如果 `Iin > 电源限流`，
说明电源无法提供所需输入功率，模型按停机处理。这是简化假设，
不是真实的 CV/CC 切换过程。

## 6. 负载区间

| 区间 | 负载电流 | 状态 | 输出电压 |
| --- | --- | --- | --- |
| 空载 | 0 A | NORMAL | 5.000 V |
| 轻载 | 0–1 A | NORMAL | 4.98–5.000 V |
| 满载 | 2 A | NORMAL | 4.960 V |
| 过载 | > 2 A | OVERCURRENT | 0 V（简化停机） |

## 7. 假设与局限

- 不考虑空载静态功耗、开关频率、电感电流纹波、输出电压纹波；
- 不考虑负载瞬态响应、温度影响、真实 MOSFET 开关损耗；
- 不考虑保护延迟与恢复时间；
- 不加入任何随机噪声，计算完全确定：同一输入必得同一输出；
- 效率是预设参数，不能用于评价真实器件能效；
- 不是 SPICE，不是硬件在环，不能作为产品合格依据。

## 8. 配置校验

`DUTConfig` 在构造时校验：数值必须是有限非布尔值；`0 < 最低输入 < 最高输入`；
标称输入在范围内；输出电压、最大电流大于 0；输出电阻非负；
`0 < 效率 ≤ 1`；额定电流下输出电压必须为正；保护策略仅支持 `shutdown`；
数据来源必须标记为 `behavioral_model`。非法配置立即抛 `ValueError`，
避免错误参数进入测试结果。
