# 12 工程性能指标定义

本文件定义第六阶段使用的指标。所有限值均为教学项目自定义假设，
不是国标、行标或真实芯片数据手册。

## 1. 电压与功率

| 指标 | 公式 | 单位 |
| --- | --- | --- |
| 输入功率 | `Pin = Vin × Iin` | W |
| 输出功率 | `Pout = Vout × Iout` | W |
| 功率损耗 | `Ploss = Pin - Pout` | W |
| 转换效率 | `η = Pout / Pin × 100` | % |
| 电压绝对误差 | `ΔV = Vout - Vnominal` | V |
| 带符号电压误差 | `ΔV / Vnominal × 100` | % |
| 绝对电压误差 | `|ΔV| / Vnominal × 100` | % |

正值表示输出偏高，负值表示输出偏低。限值判定统一使用绝对值误差，
方向信息保留在带符号误差字段中。

## 2. 负载调整率

```text
负载调整率(%) = (V空载 - V满载) / Vnominal × 100
```

分母使用**标称输出电压**。部分外部规范使用空载电压作分母，若对接
此类规范必须在报告中注明差异。

当前模型：`V空载 = 5.000 V`、`V满载(2 A) = 4.960 V`，
负载调整率为 `0.04 / 5.0 × 100 = 0.8%`。

## 3. 线性调整率

```text
线性调整率(%) = (Vout_max - Vout_min) / Vnominal × 100
线性调整率(mV/V) = |ΔVout| × 1000 / |ΔVin|
```

计算前提：输入电压变化、负载固定、所有采样均处于 `NORMAL` 状态。

当前模型输出电压只与负载电流有关，不含输入电压项，因此线性调整率
恒为 0%。这是模型结构决定的，**不代表真实电源性能**，不能与真实
数据手册的线性调整率比较。

## 4. 效率的缺失值语义

- 空载时 `Pin = 0`、`Pout = 0`，效率不可定义，输出 `None`/空值；
- 保护状态输出归零，效率同样不可定义；
- 不允许把不可定义效率写成 0% 或 100%；
- 效率超过 100% 属于数据异常，数据质量模块标记 `EFFICIENCY_ABOVE_100`。

## 5. 接口兼容与命名

已有第五阶段函数保持原语义，避免破坏既有报告与测试：

| 旧接口 | 语义 |
| --- | --- |
| `voltage_absolute_error` | 绝对电压误差（V） |
| `voltage_error_percent` | 绝对值百分比误差（%） |
| `line_regulation_percent(v_low, v_high, vin_low, vin_high)` | 外部规范风格 |

第六阶段新增：

| 新接口 | 语义 |
| --- | --- |
| `voltage_error_volts` | 带符号误差（V） |
| `signed_voltage_error_percent` | 带符号误差（%） |
| `absolute_voltage_error_percent` | 绝对值误差（%） |
| `power_loss_watts` | 允许负值，供质量检查 |
| `line_regulation_span_percent` | 按标称电压归一 |
| `line_regulation_mv_per_v` | mV/V |
| `calculate_metrics` | 统一返回 `PerformanceMetrics` |

## 6. 本阶段不实现的指标

- 纹波、噪声、瞬态响应、建立时间；
- 温漂、长期稳定性、MTBF；
- 真实保护阈值精度与保护延迟；
- 过程能力指数（Cp/Cpk）与生产良率。

原因：当前没有时间序列波形、真实器件参数与生产过程数据，伪造这些
指标会误导使用者。
